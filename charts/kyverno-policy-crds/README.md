## Values

| Key | Type | Default | Description |
|-----|------|---------|-------------|
| kyverno-api.annotations | object | `{"helm.sh/resource-policy":"keep"}` | Annotations put on every CRD. Deleting a CRD deletes every policy of that kind, and this release is nothing but CRDs, so an uninstall with no guard is the whole admission configuration of a cluster. `keep` makes Helm leave them in place, and it has to reach them through the chart -- an annotation added by hand does not survive the next upgrade. |
| kyverno-api.labels | object | `{}` | Labels put on every CRD. |
